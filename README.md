# SPIDEY BOT

SPIDEY BOT is a Discord bot and web dashboard project.

## Website

GitHub Pages:
https://spideypete.github.io/spideybot/

The GitHub Pages deployment contains the public/static website. Discord OAuth,
the live dashboard, bot APIs, payments, and other server-side functionality
remain on the SPIDEY BOT backend.

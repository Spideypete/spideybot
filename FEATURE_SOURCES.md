# SPIDEY BOT Feature Sources

SPIDEY BOT is being built as an original integration of feature ideas and workflows from public Discord-bot projects. Source code is not copied into SPIDEY BOT unless its license and any additional terms permit that use.

Reference projects:
- Logging: https://github.com/devdeem/Logger-Bot
- Server Guard: https://github.com/godbotsdiscord/God-Security-Bot
- Reaction Roles: https://github.com/Arthurdw/Reaction-Role
- Server Messages: https://github.com/topics/welcomer
- Custom Commands concepts/documentation: https://github.com/botlabs-gg/yagpdb-docs
- XP / Leaderboards: https://github.com/222ryan/Discord-Levels-Bot
- Giveaways: https://github.com/jagrosh/GiveawayBot
- Tickets: https://github.com/open-discord-bots/open-ticket
- Social Notifications: https://github.com/BankkRoll/streamer-alerts-discord-bot
- Invites: https://github.com/xathail/ReferCord
- Dashboard icons: https://phosphoricons.com/

Implementation rule:
1. Recreate functionality in SPIDEY BOT's own architecture and UI.
2. Do not copy source code or documentation text verbatim.
3. Preserve required license notices/attribution for any third-party code that is actually incorporated.
4. Do not represent a third-party project as the creator of SPIDEY BOT.
5. Review license-specific restrictions before distributing or monetizing functionality derived from a source.

The dashboard panel layer is intentionally modular: each feature has its own file under public/panels/.
